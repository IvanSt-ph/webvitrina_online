# Архив документации

Здесь сохранены аудиты, отчёты завершённых этапов и прежние подробные технические
описания. Они фиксируют состояние проекта и результаты запусков на указанных в них
датах и ревизиях. Их нельзя использовать как подтверждение текущей готовности,
актуальной конфигурации или успешности тестов.

Действующие документы находятся на уровень выше:

- [production readiness](../production-readiness-audit.md);
- [release runbook](../release-runbook.md);
- [production monitoring](../production-monitoring.md);
- [backup v3 and restore](../backup-restore-safety.md);
- [domain integrity](../domain-integrity.md).

Содержимое исторических отчётов сохранено без редакционного переписывания. Поэтому
внутренние пути, старые имена документов и ссылки на игнорируемые test/browser
artifacts могут отражать первоначальное расположение и больше не разрешаться из
архивного каталога. Это исторические ссылки, а не зависимости рабочих инструкций.
