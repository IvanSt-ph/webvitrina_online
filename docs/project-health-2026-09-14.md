## Выполненные исправления

- `RememberLocation` обрабатывает только GET/HEAD: отправленные формы и JSON больше не изменяются сохранёнными фильтрами, включая запросы с `clear_location` и подменой метода через `_method`.
- Во всех четырёх формах создания/обновления товара страна и город проверяются как положительные целые ID. Добавлены проверки массивов с существующими ID: до исправления такой запрос принимался, после исправления возвращается ошибка валидации.
- Мобильная навигация скрывается только в административном просмотре товара из чата. На обычных страницах витрины администратор по-прежнему видит её — это требование подтверждено отдельным существующим тестом.
- Во всех четырёх шаблонах JSON-LD массив создаётся внутри `@php`, затем сериализуется через `Js::encode`. Ключ `@context` больше не превращается в директиву Blade, а строки с `</script>` не могут закрыть блок JSON-LD. Проверены товар, магазин и все три шаблона категорий.
- Обновлены тестовые данные изображений, географии и резервных копий. Добавлены проверки отсутствующего изображения и миниатюры; тест неверной checksum теперь содержит остальные обязательные файлы, чтобы падать именно из-за контрольной суммы.
- Обновлены npm-зависимости в пределах заявленных основных версий. Установлены Vite 7.3.6, laravel-vite-plugin 2.1.0, concurrently 9.2.4; Axios обновлён до 1.20.0 и перенесён в runtime dependencies. `package.json`, lockfile и установленные зависимости согласованы.

## Пять упавших тестов

1. `ProductImageUrlTest::test_uploaded_product_image_uses_thumb_path` — тест задаёт путь, но не создаёт файл. Текущие локальные изменения Product проверяют наличие файла и возвращают заглушку. Нужны файловые fixtures и отдельные проверки fallback.
2. `ProductCountryCityValidationTest::test_admin_product_update_rejects_city_from_another_country` — вместо 422 получен 302. `RememberLocation`, подключённый к web middleware, удаляет несовместимый city_id до валидации. В ProductUpdateRequest поле имеет правило sometimes, поэтому отсутствие поля пропускается. Следует отделить обработку фильтров каталога от данных форм.
3. `ReleaseExperienceTest::test_backup_health_check_accepts_fresh_complete_backup_with_checksums` — fixture не содержит manifest.json и его checksum, которые теперь обязательны в BackupHealth. Это рассогласование теста с текущим форматом backup, а не доказательство поломки реальных резервных копий.
4. `SecurityRegressionTest::test_remembered_location_accepts_only_positive_integer_ids` — ожидается city_id=2, но тест не создаёт город. Middleware теперь проверяет существование города, поэтому удаляет значение. Требуется обновить тестовые данные.
5. `SecurityRegressionTest::test_admin_public_product_page_does_not_show_buyer_mobile_nav` — на публичной странице товара для администратора присутствует data-mobile-bottom-nav. Условие в layouts/app.blade.php исключает административные маршруты, но не всех администраторов.
